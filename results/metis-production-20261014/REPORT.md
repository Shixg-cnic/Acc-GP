# METIS 生产初始化切换与验证

日期：2026-10-14。按用户明确要求，唯一生产初始化改为 CPU METIS_PartGraphKway，使用与 Jet 相同的 METIS 5.2.1/GKlib。

流程：GPU SCLP 粗化 → 下载最粗加权 CSR → CPU METIS k-way → 必要的严格容量修复 → 标签上传 → GPU 投影/细化。
默认 options、单重量约束、均等目标、seed=0、imbalance=1.03。传输、转换、METIS、修复及临时缓冲回收全部计入完整初始化/算法时间。
原 GPU 谱源码、测试、入口、构建与文档在 before/；两个旧完整划分二进制另保存为 gpu-before-standard/big，不加入 Git。

粗化预算、细化规则与默认参数保持。本次不将初始化作为原创贡献。

验证通过：7项 CTest；三类合成图、2/4/8/16/32/64/128份、standard/big 共42次内部严格验证与 Python oracle；9次真实图独立 C++ oracle；standard/big 初始化 memcheck 均0错误。

完整流程检查发现 Python oracle 仍有32份上限，已统一扩展到128，并加入两个oracle在64/128份环图上的交叉核验。
