# 九类数据集比较：当前版本 vs Jet

所有加速比均为 Jet 完整算法耗时 / 当前版本完整算法耗时；大于1表示当前版本更快。
每配置先分别取时间和cut中位数，再对加速比取等权几何平均；cut变化取算术平均，正数为变差。
GPU输入上传、加载、最终标签下载/写盘及独立CSR核验不计入时间；内部初始化传输、容量修复、清理计入。
两方法seed=0、OMP=4、匹配严格容量floor(103*N/(100*k))；单次METIS初始化。
本表是用户指定六类24图与三个空白类36候选图的60图集合；不包含其余五张本地图。
三个空白类全部展示，没有按速度删除候选。失败/超载/核验失败配置不计入有效加速，单独列出。
